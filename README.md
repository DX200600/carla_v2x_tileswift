# V2X-TileSwift
基于tile冗余的车载目标检测协同卸载系统|大创创新训练项目

>计划周期：2026-11-25~2026-12-24
>仿真平台：CARLA 0.9.16|Python3.9

## 目录约定
-'src/':源代码，仿真器、各类python脚本
-'configs/':配置、超参、查表策略文件、启动脚本
-'data':原始图像、实验输出日志，该目录不上传git
-'docs/':报告、周记、技术笔记、图表素材
